# Ticketing Practice

콘서트 예매 흐름과 좌석 선택을 연습하는 웹 서비스 프로젝트입니다.

## 목표

- 예매처별 화면 흐름을 독립적인 연습 모드로 구현
- 공연장 기본 좌석 구조와 공연별 무대 배치를 분리해 관리
- 좌석 선택, 선점 실패, 재선택 상황 시뮬레이션
- 선택 소요 시간과 연습 결과 제공

## 첫 번째 구현 범위

1. 한 가지 예매 흐름
2. 한 가지 샘플 공연장 및 좌석 배치
3. 좌석 선택과 가상 경쟁 상황
4. 연습 결과 화면

현재는 저장소 초기 설정 단계이며, 기술 스택과 대상 예매처는 아직 정하지 않았습니다.
실제 예매처와 연결하지 않는 독립적인 시뮬레이션으로 개발합니다.

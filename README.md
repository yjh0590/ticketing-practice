# 첫열 · Ticketing Practice

콘서트 예매의 구역 탐색, 좌석 선택, 선점 실패 후 재선택을 연습하는 웹 앱입니다.
실제 예매처와 연결하지 않는 독립적인 시뮬레이터입니다.

## 실행

Node.js 22 이상에서 추가 패키지 설치 없이 실행할 수 있습니다.

```sh
npm start
```

브라우저에서 http://localhost:5173 에 접속하세요.
Windows PowerShell에서 실행 정책 오류가 발생하면 `npm.cmd start`를 사용하세요.

## 사용 방법

1. 공연 일시, 경쟁 난이도, 예매 매수를 정합니다.
2. 연습 시작을 누르면 3초 카운트다운 후 예매가 열립니다.
3. 구역을 누르고 좌석을 선택한 뒤 좌석 확정을 누릅니다.
4. 두 장 예매에서는 같은 구역·열의 붙어 있는 두 좌석이 필요합니다.
5. 선점에 실패하면 다른 좌석을 선택합니다. 연석까지 소진되면 연습이 종료됩니다.
6. 결과에서 소요 시간, 첫 좌석 클릭 시간, 선점 실패 횟수를 확인합니다.

최근 30개 결과는 브라우저 localStorage에 저장됩니다. 계정 간 동기화는 없습니다.
브라우저 저장소가 차단되어도 연습할 수 있으며, 기록은 현재 창에서만 유지됩니다.

## 구현 범위

- 가상의 서울 라이브 아레나, 5개 구역·480개 좌석 (공연 배치에서 2석 제외)
- 기본 공연장 구조와 공연별 판매 제외석 분리
- 하나의 PC 예매 흐름, 1매/연석 2매 선택
- 세 단계 난이도, 실시간 가상 선점, 확정 응답 지연
- 성공/좌석 소진 결과와 로컬 연습 기록
- 데스크톱 및 모바일 레이아웃, 키보드 좌석 선택

공연 일시 두 개는 동일한 가상 배치를 사용합니다. 실제 공연 일정이 아닙니다.
실제 예매처별 화면 분석과 공연장 데이터 수집은 아직 진행하지 않았습니다.
결제·로그인·실제 티켓 구매 기능은 없습니다.

## 구조

- `index.html`, `styles.css`: 화면과 반응형 스타일
- `app.js`: 예매 단계, 경쟁 타이머, 결과 및 기록
- `lib/simulation.js`: 공연장/공연 배치, 좌석 검증 및 경쟁 로직
- `scripts/serve.mjs`: 로컬 개발 서버 (명시한 앱 파일만 제공)
- `test/simulation.test.js`: 연석, 선점 경쟁, 좌석 소진 테스트

```sh
npm test
npm run check
```

실제 브라우저 검증은 개발 의존성을 설치한 뒤 실행합니다.
기본적으로 PC에 설치된 Microsoft Edge를 사용합니다.

```sh
npm ci
npm run test:browser
```

화면 확인용 캡처는 무시된 `artifacts/` 폴더에 생성됩니다.
기본 포트가 사용 중이면 PowerShell에서 `$env:PORT=5187; npm.cmd start`로 실행하세요.

다음 확장은 실제 예매처 한 곳의 접근 가능한 화면 흐름을 조사하고,
별도 UI 모드와 이용 가능한 공연장 데이터를 추가하는 것입니다.

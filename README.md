# 첫열 · Ticketing Practice

공연·스포츠·기차·영화 예매처 17곳의 예매 흐름을 연습하는 독립 웹 앱입니다.
예매처마다 단계 구성이 다르며, 끝까지 가상 결제를 완료하면 좌석 확보/전체 시간을 기록합니다.

| 예매처 | 형태 | 흐름 |
| --- | --- | --- |
| NOL · 인터파크 | PC형 (구역 패널 오른쪽) | 날짜 → 좌석 → 할인 → 배송/주문자 → 결제 |
| YES24 티켓 | PC형 (구역 패널 왼쪽, 쿠폰) | 날짜 → 좌석 → 할인/쿠폰 → 수령 → 결제 |
| 티켓링크 | PC형 (구역 패널 왼쪽, PAYCO) | 날짜 → 좌석 → 할인 → 배송 → 결제 |

| 타임티켓 | 할인형 (상품 선택 후 좌석 자동배정) | 날짜 → 할인 상품 → 예매 확인 → 결제 |

가상 이벤트는 여섯 가지입니다: 콘서트, 프로야구 경기, 대학로 연극, 설 명절 열차(서울→부산), 영화 특별관 상영, 축구 국가대표 친선경기.
연습 설정에서 공연장·경기장을 고르면 그 장소의 배치도로 연습합니다.

| 종류 | 고를 수 있는 장소 |
|---|---|
| 콘서트 | 서울 라이브 아레나(기본·가상), KSPO DOME, 고척스카이돔, 인스파이어 아레나, 서울월드컵경기장, 세종문화회관 대극장, 블루스퀘어 신한카드홀, 샤롯데씨어터 |
| 프로야구 | 연습 볼파크(기본·가상), 잠실야구장, 인천SSG랜더스필드, 창원NC파크, 사직야구장 |
| 연극 | 대학로 연습극장(가상) |
| 명절 열차 | KTX-산천 8량 (3호차 특실 2+1, 나머지 일반실 2+2) |
| 영화 | CGV 용산아이파크몰 IMAX관, CGV 연습 일반관(가상), 메가박스 코엑스 돌비시네마, 메가박스 연습 일반관(가상) |
| 축구 | 서울월드컵경기장 (A매치) |

실제 장소는 전체 모양·층 구성·좌석 등급 이름을 공개 자료에서 참고해 **단순화한 연습용 배치도**입니다.
구역 수·구역 번호·좌석 수·가격은 예시이며 실제 공연별 배치도와 다릅니다.
할인형(타임티켓·엘티켓)은 상품이 기본 장소의 구역에 묶여 있어 장소를 바꿀 수 없습니다.

## 실행

Node.js 22 이상에서 앱 실행에는 추가 패키지 설치가 필요하지 않습니다.

```sh
npm start
```

기본 주소는 http://127.0.0.1:5173 입니다.
PowerShell 실행 정책 오류가 나면 `npm.cmd start`를 사용하세요.
포트가 사용 중이면 아래처럼 다른 포트로 실행할 수 있습니다.

```powershell
$env:PORT=5187; npm.cmd start
```

## 사용 방법

1. 17개 예매처 중 하나를 선택합니다.
2. 공연장·경기장, 난이도, 목표 매수, 대기열·보안문자·연석 옵션을 설정합니다.
3. 공연 날짜를 고르고 예매 버튼을 누르면 3초 후 연습창이 열립니다.
4. 이용 확인·제휴 안내 단계는 확인 체크, 선예매 인증은 화면의 가상 멤버십 번호를 입력해 통과합니다.
5. 날짜/회차 확인 후 구역과 작은 사각형 좌석을 선택합니다. 할인형은 상품을 고르면 좌석이 자동 배정됩니다.
6. 좌석 선택 완료를 누릅니다. 선점에 실패하면 다른 좌석을 선택합니다.
7. 할인·수령(또는 예매 확인)·결제수단을 거쳐 최종 확인에 동의해 가상 결제를 완료합니다.
8. 결과에서 좌석 확보 시간·전체 시간·실패 횟수를 확인합니다.

좌석 확보 이후에는 연습용 3분 유지 시간이 적용됩니다. 시간 초과 시 좌석을 다시 선택합니다.
창의 × 또는 Esc로 진행 중인 연습을 중단할 수 있습니다.
2매 예매는 기본적으로 떨어진 좌석도 허용하며, 연석 옵션을 켜면 붙은 좌석만 가능합니다.
최근 30회 기록은 브라우저 localStorage에 저장됩니다. 이전 버전 기록도 표시합니다.

## 재현 범위

공개 예매 안내를 기반으로 PC 예매창의 단계·배치·버튼 동작을 직접 구현했습니다.
**최신 로그인 예매 화면과 픽셀 단위로 동일한 복제본은 아닙니다.**
기본 장소 3곳(아레나·볼파크·연습극장)은 가상이고, 실제 장소 10곳은 공개 자료의 전체 구조만 참고해 단순화했습니다.
대기열·경쟁·보안문자·유지 시간·금액은 모두 연습용이며 실제 서비스 규칙이 아닙니다.
실제 개인정보를 입력받지 않고, 실제 결제나 예매처에 대한 요청을 보내지 않습니다.
[공개 자료와 구현 한계](docs/provider-references.md)를 참고하세요.

## 구조 및 검증

- `lib/providers.js`: 예매처별 단계 순서(`flow`)·레이아웃·결제수단과 달력 데이터
- `lib/venues.js`: 장소 21곳(공연장·야구장·KTX·영화관·축구장)의 구역·등급·배치도 도형(SVG)
- `lib/simulation.js`: 좌석 검증·선점 경쟁·자동 배정·수요 기반 가격
- `app.js`: `flow`를 따라 단계를 렌더링하는 예매창, 유지 시간, 기록
- `scripts/serve.mjs`: 허용된 앱 파일만 제공하는 로컬 서버
- `test/simulation.test.js`: 좌석 검증·소진·자동 배정·가격 변동·예매처 설정 일관성, 장소별 좌석 id·배치도 범위 테스트
- `scripts/browser-check.mjs`: 17개 예매처 전체 흐름과 실제 장소 4곳(KSPO DOME·세종문화회관·랜더스필드·사직)·KTX·영화관·A매치 예매 브라우저 검증

```sh
npm test
npm run check
npm ci
npm run test:browser
```

브라우저 검증은 PC에 설치된 Microsoft Edge를 사용합니다.
다른 설치된 브라우저는 `BROWSER_CHANNEL=chrome` 등으로 지정할 수 있습니다.
검증 캡처는 Git에서 제외한 `artifacts/` 폴더에 생성됩니다.
